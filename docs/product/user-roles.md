# User roles

## Operador

Main user of the incident intake flow. The operator:

- submits a new ticket
- receives category, priority, and similar solutions
- evaluates whether the suggested path is useful
- continues the support workflow with the system as a recommendation layer

## Experto KEDB

Responsible for validating generated KEDB drafts. The expert:

- reviews pending drafts
- edits, approves, or rejects generated content
- checks traceability to source tickets
- decides whether the article is ready to be reused in the search layer

## Coordinador

Focuses on operational oversight and metrics. The coordinator:

- checks coverage and quality indicators
- monitors trends and recurring issues
- validates that the solution is actually improving operational support

## Product logic

The product is designed to assist humans, not replace them. Final decisions remain with the operator and the expert, while the system provides evidence-based suggestions and structured knowledge reuse.
