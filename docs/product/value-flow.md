# Value flow

## 1. Intake

A new ticket enters the system from the operator interface or a supported channel.

## 2. Classification and prioritization

The system determines:

- category
- confidence level
- priority score
- business context of the incident

## 3. Retrieval

The system searches for similar historical tickets and already validated KEDB articles.

## 4. Resolution and learning

When a ticket is resolved, that information becomes candidate material for knowledge consolidation.

## 5. KEDB generation

Related tickets are grouped and transformed into draft KEDB articles.

## 6. Human validation

The expert reviews the draft, confirms the facts, and approves it or sends it back for correction.

## 7. Reuse

Validated articles become part of the retrieval index so that future similar incidents benefit from the accumulated knowledge.

This is the core value loop of the product: assistance generates knowledge, and knowledge improves the next assistance cycle.
